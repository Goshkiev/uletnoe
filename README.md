# Кафе «Улётное» — сайт-меню

Мобильный сайт с меню, на который гости попадают по QR-коду. Статический сайт без сборки, хостится на GitHub Pages.

## Как поменять меню

Всё меню лежит в одном файле: [`menu.json`](menu.json). Сайт сам перерисуется после сохранения.

- **Цена:** поменяйте `"price"` у блюда (или `"price"` внутри `"variants"`, если у блюда несколько размеров).
- **Временно убрать блюдо (стоп-лист):** добавьте блюду `"hidden": true`.
- **Новое блюдо:** скопируйте похожее блюдо целиком и поменяйте `id` (латиницей, уникальный), название, цену, состав.
- **Фото:** положите файл в папку `img/` и укажите путь в поле `"img"`, например `"img/teisti.jpg"`.
- **Адрес, телефон, часы работы:** заполните поля в блоке `"cafe"` вверху файла, они появятся внизу страницы.

Поля блюда:

| поле | что это |
|---|---|
| `id` | уникальный код блюда латиницей (пригодится для корзины) |
| `name` | название |
| `price` | цена в рублях |
| `variants` | размеры: `[{ "label": "390 г", "price": 320 }, …]` вместо `price` |
| `weight` | вес или объём |
| `desc` | состав |
| `nutrition` | `[белки, жиры, углеводы, ккал]` |
| `img` | путь к фото |
| `hidden` | `true` — не показывать |

## Локальный запуск

```sh
python3 -m http.server 8000
# открыть http://localhost:8000
```
