# Настройка приёма заказов

Заказы с сайта сохраняются в бесплатной базе [Supabase](https://supabase.com) и сразу появляются на экране кафе. Настраивается один раз, примерно за 10 минут.

## 1. Создать проект Supabase

1. Зарегистрируйтесь на https://supabase.com (проще всего кнопкой «Continue with GitHub»).
2. **New project** → название `uletnoe`, регион **Central EU (Frankfurt)**, придумайте пароль базы (сохраните его, но нам он не понадобится) → **Create new project**.

## 2. Создать таблицу заказов

1. Слева **SQL Editor** → **New query**.
2. Скопируйте целиком содержимое файла [`supabase/schema.sql`](supabase/schema.sql), вставьте и нажмите **Run**. Должно появиться «Success».
3. В новом запросе впишите e-mail сотрудников, которые будут видеть заказы, и нажмите **Run**:

   ```sql
   insert into public.staff_emails (email) values
     ('kafe@example.com'),      -- экран в кафе
     ('manager@example.com')    -- телефон управляющего
   on conflict do nothing;
   ```

## 3. Создать аккаунты сотрудников

1. Слева **Authentication** → **Users** → **Add user** → **Create new user**.
2. Введите e-mail из шага 2.3 и пароль, отметьте **Auto Confirm User** → **Create user**. Повторите для каждого сотрудника.
3. Для надёжности: **Authentication** → **Sign In / Providers** → выключите **Allow new users to sign up**. Тогда новых сотрудников добавляете только вы.

## 4. Подключить сайт

1. Слева **Project Settings** → **Data API** скопируйте **Project URL**, затем **API Keys** скопируйте ключ **anon public**.
2. Впишите их в [`config.js`](config.js) (или пришлите Claude, он впишет сам):

   ```js
   window.ULETNOE_CONFIG = {
     supabaseUrl: 'https://xxxx.supabase.co',
     supabaseAnonKey: 'eyJhbGciOi…',
   };
   ```

   Ключ anon публичный и рассчитан на то, что его видно в браузере. Доступ к заказам защищён правилами в базе: гости могут только оформить заказ и узнать статус своего.

После этого на сайте появится корзина.

## 5. Экран в кафе

1. Откройте https://goshkiev.github.io/uletnoe/admin/ на планшете или компьютере кафе и войдите.
2. Нажмите кнопку **«Нажмите, чтобы включить звук»** (браузеры не дают сайтам пищать без одного нажатия) и разрешите уведомления.
3. Оставьте вкладку открытой. Пока есть невзятые заказы, экран пищит каждые 5 секунд и не даёт планшету уснуть.

## 6. Приложение управляющего

Та же страница `…/admin/` ставится на телефон как приложение:

- **Android (Chrome):** меню ⋮ → **Установить приложение** / **Добавить на главный экран**.
- **iPhone (Safari):** кнопка **Поделиться** → **На экран «Домой»**.

Заказы и статусы синхронизируются между всеми устройствами мгновенно.

## Ограничения сейчас

- Звук и уведомления работают, пока приложение открыто (на Android обычно и в фоне). Уведомления на закрытое приложение (push) или дубль в Telegram — следующий шаг.
- Бесплатный проект Supabase засыпает, если им не пользоваться 7 дней. Тогда его нужно «разбудить» кнопкой **Restore** в панели Supabase.
- Цены в заказе приходят с сайта. Оплата всё равно на кассе, поэтому кассир пробивает реальные цены.
