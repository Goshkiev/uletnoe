# Запуск на своём сервере в России

Сайт, приём заказов и база работают на одном сервере. Внешних сервисов нет: шрифты свои, данные гостей хранятся только на этом сервере (152-ФЗ, локализация ПДн).

## Что нужно

- Облачный сервер с **Ubuntu 24.04** в российском дата-центре (например, Timeweb Cloud или Selectel), самая простая конфигурация.
- Домен (например, `uletnoe-cafe.ru`), у которого A-запись указывает на IP сервера. Для теста можно без домена: сайт откроется по адресу вида `1-2-3-4.sslip.io`.

## Установка

Откройте консоль сервера (в панели хостинга) и выполните одну команду:

```sh
curl -fsSL https://raw.githubusercontent.com/Goshkiev/uletnoe/main/deploy/install.sh | sudo bash -s -- uletnoe-cafe.ru you@example.com
```

Без домена: `... | sudo bash`. Скрипт:

1. ставит nginx, certbot и Node.js;
2. скачивает код в `/opt/uletnoe`, запускает сервер заказов (`uletnoe.service`), база лежит в `/var/lib/uletnoe`;
3. получает бесплатный HTTPS-сертификат;
4. каждые 5 минут подтягивает изменения из ветки `main` на GitHub;
5. создаёт сотрудников `kafe` и `manager` и печатает их пароли.

Скрипт можно запускать повторно, например когда появится домен.

## Сотрудники

```sh
cd /opt/uletnoe/server
sudo -u uletnoe env DATA_DIR=/var/lib/uletnoe node cli.js list-users
sudo -u uletnoe env DATA_DIR=/var/lib/uletnoe node cli.js add-user ira
sudo -u uletnoe env DATA_DIR=/var/lib/uletnoe node cli.js set-password manager
sudo -u uletnoe env DATA_DIR=/var/lib/uletnoe node cli.js remove-user ira
```

## Экран кафе и приложение управляющего

- **Кафе:** откройте `https://<домен>/admin/` на планшете или компьютере и войдите. Нажмите кнопку звука и разрешите уведомления. Пока есть невзятые заказы, экран пищит каждые 5 секунд и не гаснет.
- **Управляющий:** та же ссылка на телефоне → «Установить приложение» (Android) или «Поделиться → На экран „Домой“» (iPhone). Разрешите уведомления: они приходят, даже когда приложение закрыто. Через серверы Google и Apple идёт только пустой сигнал, без телефона и состава заказа.

## Персональные данные

- При заказе гость ставит галочку согласия. Тексты лежат в `legal/consent.html` и `legal/privacy.html`. **Впишите в них реквизиты оператора** (ИП или ООО, ИНН, адрес, e-mail): сейчас там стоят квадратные скобки.
- Телефон, имя, комментарий и IP заказа автоматически стираются через 30 дней (`RETENTION_DAYS` в `/etc/uletnoe.env`).
- Оператор ПДн должен подать уведомление в Роскомнадзор: pd.rkn.gov.ru → «Уведомление об обработке персональных данных».

## Обслуживание

- Логи сервера: `journalctl -u uletnoe -f`, логи обновлений: `/var/log/uletnoe-update.log`.
- Резервная копия базы: `sqlite3 /var/lib/uletnoe/uletnoe.sqlite ".backup /root/uletnoe-$(date +%F).sqlite"`.
- Тесты сервера: `cd server && npm test` (нужен Node.js 22.13+).
